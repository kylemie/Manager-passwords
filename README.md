Менеджер паролей для http сервисов

Возможности:
1) Добавлять новый аккаунт
   а) Логин
   б) Пароль (Если не ввести то программа сама сгенерирует)
   в) Ссылка на http сервис
2) Найти аккаунт по логину
3) Удалить аккаунт по логину
4) Завершить программу

Хранение данных происходит в JSON формате:
login,
password,
url,
createdAt (дата и время создания),
updateAt (дата и время изменения данных)
